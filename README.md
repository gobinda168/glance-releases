# glance-releases

**Glance Studio's releases have moved to [gobinda168/glance-studio](https://github.com/gobinda168/glance-studio/releases)**,
the app's open-source repository, where every release is tagged on the source it was built from.

Download the latest: https://github.com/gobinda168/glance-studio/releases/download/feed-terminal/Glance-Studio.dmg

This repository keeps the old releases and the update feed that Glance Studio 0.1.0-beta.17 and earlier check, so
those builds still update (onto a version that reads the new feed). It will be archived once they have moved.
